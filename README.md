## 📌 Overview
**FinSight AI** is an intelligent financial statement analysis and review platform designed for automated financial document auditing, ratio computation, anomaly detection, peer benchmarking, and automated PDF report generation.

### Key Features
- **Data Quality & Schema Validation**: Automated parsing and schema verification for CSV/Excel financial data.
- **Financial Metric Engine**: Automatic computation of 100+ liquidity, profitability, leverage, and efficiency ratios.
- **Anomaly & Risk Detection**: AI-assisted anomaly identification and forensic financial risk scoring.
- **Peer Benchmarking & Visualization**: Interactive charts for cross-company comparison and trend analysis.
- **Automated Executive Report PDF Generation**: Download ready-to-present financial analysis PDF reports.

## 🚀 Running Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/mkondaka-maker/HACKTHON-FRONTEND.git
   cd HACKTHON-FRONTEND
   ```

2. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the Streamlit app**:
   ```bash
   streamlit run app.py
   ```
   Open `http://localhost:8501` in your browser.
